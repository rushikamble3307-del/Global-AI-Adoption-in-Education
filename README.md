# Global AI Adoption in Education: A Comprehensive Performance Intelligence Report

## 📌 Project Overview
This project analyzes the adoption, usage patterns, and growth of Artificial Intelligence across the global education sector using Tableau. It compares adoption rates across countries, regions, rural vs. urban areas, students vs. teachers, and tracks trends over time.
